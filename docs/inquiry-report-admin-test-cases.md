# 문의 및 신고 어드민 핵심 QA TC

## 수행 기준

- 대상 화면: 문의 및 신고 (`/report/inquiry`)
- 테스트 범위: 조회 23개, 변경 6개로 총 29개 TC
- 실제 dev 환경에서 확인하며, 변경 테스트는 전용 QA 데이터를 사용하고 종료 후 정리한다.
- 목록·작성자 메뉴·댓글·화면 배치는 현재 UI 기준으로 확인한다.

## Playwright 실행 정보

- 확인일: `2026-11-14`
- 실제 API E2E: TC 28개 통과, 1개 데이터 부족으로 생략
- 로그인 준비 포함: 29개 통과, 1개 생략 (3.9분)
- 관련 단위·통합 테스트 180개, 린트·프로덕션 빌드 통과
- 수집 확인: TC 29개와 로그인 준비 1개, 총 30개
- 실행 환경·설정: [E2E 공통 가이드](./playwright-e2e-guide.md)
- 기능별 실행 범위·준비 데이터: [문의·신고 E2E README](../e2e/features/inquiry-report/README.md)

## 실행 방법

```bash
# 최근 변경에 대한 조회 회귀 테스트
npx playwright test e2e/features/inquiry-report/inquiry-report-authors.read.spec.ts --project=dev-read

# 문의·신고 전체 테스트
npx playwright test e2e/features/inquiry-report --project=dev-read --project=dev-write

# HTML 결과 확인
npm run test:e2e:report
```

## 실서버 수동 QA용 최소 준비 데이터

- 목록·페이지 이동을 확인할 문의·신고 데이터
- 일반 작성자·탈퇴 작성자, 수정된 글, 담당자가 있는 글과 없는 글
- 신고 대상이나 첨부파일이 있는 글
- 댓글·대댓글 확인과 변경 테스트에 사용할 전용 QA 글

## 기능 1. 목록, 필터, 페이지네이션

| TC ID         | 테스트 항목           | 테스트 절차                                    | 기대 결과                                                                                        | 최근 E2E 결과 |
| ------------- | --------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------ | ------------- |

| TC-ADM-IR-002 | 목록 기본 정보        | 목록의 열과 게시글 ID 복사 확인                | postId·유형·카테고리·작성자 아이디·답변여부·제목·작성일·담당자가 표시되고 ID 복사가 동작함       | 통과          |
| TC-ADM-IR-003 | 분류와 탈퇴 표시      | 문의·신고·탈퇴 작성자가 있는 행 확인           | 분류와 작성자 상태가 기존 공통 배지로 표시됨                                                     | 통과          |
| TC-ADM-IR-004 | 유형 필터             | 문의 또는 신고 선택                            | 선택 즉시 해당 유형만 표시되고 첫 페이지로 이동함                                                | 통과          |
| TC-ADM-IR-005 | 카테고리 필터         | 유형 선택 후 카테고리 변경                     | 해당 유형의 카테고리를 선택할 수 있고 결과가 즉시 반영됨                                         | 통과          |
| TC-ADM-IR-006 | 필터 초기화           | 유형 변경 및 필터 X 클릭                       | 유형 변경 시 카테고리가 초기화되고 X로 해당 조건을 해제할 수 있음                                | 통과          |
| TC-ADM-IR-007 | 답변 상태 필터        | 답변 전·답변 완료·이용자 철회 선택             | 선택 즉시 해당 상태의 결과만 표시됨                                                              | 통과          |
| TC-ADM-IR-008 | 복합 필터와 빈 결과   | 여러 필터와 검색어를 조합하고 검색어 해제      | 조건에 맞는 결과 또는 빈 결과 안내가 표시됨                                                      | 통과          |
| TC-ADM-IR-009 | 페이지 이동           | 1페이지에서 2페이지로 이동                     | 10개 단위로 목록이 바뀌고 URL에 페이지가 반영됨                                                  | 통과          |
| TC-ADM-IR-029 | 통합 검색과 즉시 필터 | 학번·아이디·내용으로 검색하고 필터 변경·초기화 | 검색어는 버튼·Enter로 적용되고 검색 영역 안의 필터는 즉시 적용됨. 초기화 시 입력과 조건이 해제됨 | 통과          |

답변 상태 필터는 현재 프론트에서 처리한다. 전체 페이지 정보와 서버 상태 필터가 제공되면 현재 페이지만 조회하는 방식으로 전환할 수 있다.

| TC-ADM-IR-014 | 원문 이동          | 문의·신고 원문 버튼 클릭                        | 해당 유저 화면의 원문이 새 탭으로 열림                                                    | 통과          |

## 기능 4. 댓글 및 대댓글

| TC ID         | 테스트 항목        | 테스트 절차                                   | 기대 결과                                                      | 최근 E2E 결과        |
| ------------- | ------------------ | --------------------------------------------- | -------------------------------------------------------------- | -------------------- |
| TC-ADM-IR-020 | 댓글 목록과 건수   | 여러 페이지의 공개·숨김 댓글이 있는 상세 확인 | 다음 페이지를 포함한 공개 댓글·대댓글이 표시되며 건수가 일치함 | 통과                 |
| TC-ADM-IR-021 | 작성자와 관리 메뉴 | 일반·탈퇴·관리자 작성 댓글 확인               | 작성자 정보와 상태가 구분되고 작성한 댓글에 관리 메뉴가 표시됨 | 데이터 부족으로 생략 |
| TC-ADM-IR-022 | 댓글 등록          | 빈 값·공백·최대 길이 입력 후 등록             | 입력 조건을 확인하고 정상 등록 시 목록·건수·답변 상태가 갱신됨 | 통과                 |
| TC-ADM-IR-023 | 대댓글             | 대상 선택·취소 후 대댓글 등록                 | 선택 상태가 구분되고 해당 댓글 아래에 대댓글이 표시됨          | 통과                 |
| TC-ADM-IR-024 | 댓글 수정          | 수정 취소 후 다시 저장                        | 취소 시 원문이 유지되고 저장 시 내용과 수정됨 표시가 반영됨    | 통과                 |
| TC-ADM-IR-025 | 댓글 삭제          | 작성한 댓글 삭제                              | 목록과 건수에서 해당 댓글이 제외됨                             | 통과                 |

TC-ADM-IR-021은 탈퇴 작성자의 공개 댓글 데이터가 없어 실서버 검증을 생략했다. 해당 작성자 표시는 단위·통합 테스트로 확인했다. 댓글 조회 실패 안내와 재시도도 단위·통합 테스트로 확인했다.
